# Phenomena vision

## Product thesis

Make the invisible tangible. A Phenomena Lab should let a person change a parameter, watch a result emerge, and inspect the model that connects the two. The primary interaction is an experiment, not a lesson page.

## Foundation v1

Foundation v1 establishes the product shell and the first Nuclear Collection:

1. Decay Lab: stochastic decay at particle level and the population curve.
2. Nuclide Atlas: nuclear data as a map and a navigable genealogy.
3. Detector Lab: a clearly simplified comparison of detector response.
4. Pulse Lab: event accumulation and the visual emergence of spectrum-like structure.

The four Labs share a manifest, registry, language controls, state persistence, source notes, and safety boundary. Shared code remains small and is extracted only where multiple Labs use it.

## Design language

Phenomena extends the original paper-like visual language: warm cream surfaces, black rules, monospaced labels, editorial spacing, and restrained color used to mark scientific states. It does not use child-oriented worksheet styling, neon science-fiction effects, or ornamental dashboard chrome.

## Long horizon

The platform can eventually cover counting, clouds, binding, quantum, electromagnetism, thermodynamics, astronomy, chemistry, materials, biology, and statistics. Foundation v1 deliberately does not implement those domains or a general authoring studio. It establishes a stable place for them to land.
